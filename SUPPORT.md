# Contact SIGS

Email [sigs@uci.edu](mailto:sigs@uci.edu) to ask about participation, event details, volunteering, or collaboration. Use the same address for accessibility help or an archive or photo removal request that needs private context.

For a reproducible website problem or a correction that can be discussed publicly, use the [website issue tracker](https://github.com/sigs-uci/sigs-uci.github.io/issues). Include the public page URL and a short description. For the organization profile itself, use [this repository's issue tracker](https://github.com/sigs-uci/.github/issues).

Public issues are visible to everyone. Do not include attendee information, private messages, phone numbers, passwords, or account recovery details. Security concerns should follow [SECURITY.md](SECURITY.md).
