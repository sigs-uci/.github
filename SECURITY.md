# Report a security concern privately

Email [sigs@uci.edu](mailto:sigs@uci.edu) with the subject `Security report` if you find a security problem in a SIGS repository or website. Do not describe an uncorrected vulnerability or exposed personal information in a public issue.

Describe the affected public URL or repository path, the behavior you observed, and the steps needed to reproduce it. Redact credentials and personal information. Do not send passwords, recovery codes, or an unredacted copy of exposed data.

Limit any verification to your own data and authorized access. If you find information belonging to someone else, stop examining it and report where you encountered it. Please coordinate public disclosure through the organization contact after the concern has been assessed.
