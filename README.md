# SIGS on GitHub

We keep the [SIGS organization profile](https://github.com/sigs-uci) here in English and Persian, along with shared guidance for people helping with our repositories. SIGS is the Society of Iranian Graduate Students at UC Irvine.

The website is available in [English](https://sigs-uci.github.io/en/) and [Persian](https://sigs-uci.github.io/fa/). Its pages, event records, media and officer editing instructions belong in the separate [website repository](https://github.com/sigs-uci/sigs-uci.github.io). Keep rosters and event details there so the profile can link to their maintained versions.

## Edit the organization profile

1. Update [profile/README.md](profile/README.md), which appears on the organization's Overview page. Keep both introductions short and consistent, and check that their activity descriptions and contact links are current.
2. Preview it as GitHub Markdown. Check the logo, heading order, reading direction, and every link on a narrow screen as well as a wide one. Keep the full organization name as text.
3. Review the diff, then commit and push the reviewed files to `main` with the maintainer's own verified Git identity. Publishing this file changes the public organization profile. No build step is needed for this repository.

The original SIGS logo is in [profile/assets/sigs-logo.png](profile/assets/sigs-logo.png). Preserve the emblem and its proportions. The organization avatar is set separately in [GitHub's organization settings](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile#changing-your-organizations-profile-picture); changing the README image does not update it.

## Shared files

[CONTRIBUTING.md](CONTRIBUTING.md) explains public corrections. [SUPPORT.md](SUPPORT.md) routes questions, and [SECURITY.md](SECURITY.md) provides a private contact for security reports. The [issue forms](.github/ISSUE_TEMPLATE/) collect public website problems and content corrections without requesting personal details.

GitHub uses supported community files here as defaults when an organization repository has no file of that type. If a repository has its own issue templates or template configuration, it uses those instead of these defaults. See [GitHub's default community file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) before changing their placement. Workflows do not inherit from this repository.

Questions about SIGS go to [sigs@uci.edu](mailto:sigs@uci.edu). Do not put credentials, personal contact details, or unpublished records in public issues or repository files.
