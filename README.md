# SIGS on GitHub

We keep the public GitHub introduction for the Society of Iranian Graduate Students at UC Irvine here in English and Persian, along with shared guidance for people helping with our repositories.

The website has its own repository: [sigs-uci/sigs-uci.github.io](https://github.com/sigs-uci/sigs-uci.github.io). Edit website pages, event records, and website workflows there.

## Edit the organization profile

1. Update [profile/README.md](profile/README.md). Keep both introductions short and consistent, and check that their activity descriptions and contact links are current.
2. Preview it as GitHub Markdown. Check the logo, heading order, reading direction, and every link on a narrow screen as well as a wide one. Keep the full organization name as text.
3. Have the change reviewed, then commit and push the reviewed files to `main` with the maintainer's own verified Git identity. Publishing this file changes the public organization profile.

The original SIGS logo is in [profile/assets/sigs-logo.png](profile/assets/sigs-logo.png). Preserve the emblem and its proportions.

## Shared files

[CONTRIBUTING.md](CONTRIBUTING.md) explains public corrections. [SUPPORT.md](SUPPORT.md) routes questions, and [SECURITY.md](SECURITY.md) provides a private contact for security reports. The [issue forms](.github/ISSUE_TEMPLATE/) collect public website problems and content corrections without requesting personal details.

GitHub uses supported community files here as defaults when an organization repository has no file of that type. Issue templates also have inheritance rules. See [GitHub's default community file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) before changing their placement. Website workflows belong in the website repository and do not inherit from this one.

Questions about SIGS go to [sigs@uci.edu](mailto:sigs@uci.edu). Do not put credentials, personal contact details, or unpublished records in public issues or repository files.
